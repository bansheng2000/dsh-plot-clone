# pl 数据契约

> 来源：https://github.com/hang-jin/editaplot `runtime/templates/pl/data_contract.md`（Apache-2.0）。本文件按本 skill 字段重写，非原文照抄。

## 需要什么数据

- **用途**：绘制稳态、多条件发射谱或时间分辨 PL 衰减。
- **必填列**：Wavelength 或 Time、一个或多个 PL 数值系列
- **可选列**：与测量列同名并以 Fit/拟合结尾的用户拟合列
- **数据布局**：宽表；稳态多条件系列按源列顺序保留
- **最少列数**：2
- **列名别名**（识别用）：Wavelength/波长、Time/时间、PL intensity/发光强度、Fit/拟合

## 列角色（机器读，见同目录 `schema.json`）

| 角色 | 是否必填 |
|---|---|
| `x` | 必填 |
| `series` | 必填 |
| `fit` | 可选 |

## 判据

- 不自动归一化、平滑、拟合或计算寿命。
- TRPL 对数轴要求所有显示值为正。
- 拟合列按去掉 Fit/拟合后的名称与测量列配对。
- 波长加多条强度列但没有明确 PL/发射语义时，必须让用户确认，不能与 UV–Vis 自动混淆。
- 温度、时间或处理条件的顺序来自源列顺序，不从数值大小重新排序。
- **本 skill 尚未实跑**，以上列约束来自上游声明，未逐条验证。
