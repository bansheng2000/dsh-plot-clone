# flim_phasor 数据契约

> 来源：https://github.com/hang-jin/editaplot `runtime/templates/flim_phasor/data_contract.md`（Apache-2.0）。本文件按本 skill 字段重写，非原文照抄。

## 需要什么数据

- **用途**：上传 G、S、Group 长表；相量坐标须在上游计算完成，本模板只负责可编辑展示。
- **必填列**：G、S、Group
- **数据布局**：长表，每行一个相量观测
- **最少列数**：3
- **列名别名**（识别用）：相量G、相量S、分组、组别

## 列角色（机器读，见同目录 `schema.json`）

| 角色 | 是否必填 |
|---|---|
| `x` | 必填 |
| `series` | 必填 |
| `category` | 必填 |

## 判据

- 原生构建器已通过 Origin 2024b 的四格式、逐值反读及工程重开；每次正式运行仍需通过当前主机与数据门禁。
- 映射 G 到 x、S 到 series、Group 到 category；中文列名或额外列须确认含义，不将其他数值列自动当作相量。
- 支持 1–8 个显式组；G/S 必须为有限实数，Group 不可为空，保留组首次出现顺序与全部原始观测。
- 181 点参考半圆的圆心为 (0.5, 0)、半径为 0.5；它是需明确审批的数学参考，不是实验数据。
- 圈外点保留并提示，不自动删点、拟合、聚类、推算寿命或混合比例。
- G 与 S 每单位实际物理长度保持一致；页面尺寸按数据范围和图例空间调整。
- **本 skill 尚未实跑**，以上列约束来自上游声明，未逐条验证。
